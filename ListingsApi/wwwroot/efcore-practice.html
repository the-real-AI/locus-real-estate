Таблица Districts

DbSet<District> Districts
1 (Родитель)
Колонка Тип в C# / SQL Правила EF Core
Id int / INTEGER PRIMARY KEY AUTOINCREMENT
Name string / TEXT(100) IsRequired(), HasIndex().IsUnique()
Listings List<Listing> Навигационное свойство 1:N
Правило удаления: OnDelete(DeleteBehavior.Restrict) — район, в котором есть хотя бы одно объявление, удалить из базы нельзя!
L

Таблица Listings

DbSet<Listing> Listings
∞ (Многие)
Колонка Тип C# / SQLite Специфика EF Core 10
Id int / INTEGER PRIMARY KEY
Title string / TEXT(200) IsRequired()
Price decimal / REAL HasConversion<double>() для SQLite
DistrictId int / INTEGER FOREIGN KEY → Districts(Id)
Особенность SQLite: SQLite не имеет нативного типа decimal. Без HasConversion<double>() сортировка и фильтрация по цене будут работать некорректно!
